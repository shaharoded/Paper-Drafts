The architecture

Ben-Gurion University of the Negev · Shahar Oded

13

About 2 minutes. Walk left to right. Input: the interval records (from the TAK repository via the Mediator) and a static context vector (age, sex, prior admissions in 6 and 12 months, prior complications, chronic-condition flags, home vs in-hospital medication flags, a modified Charlson index). EMR embedder: hierarchical token embedding concatenated with Time2Vec absolute time, projected and normalized. Context is projected separately. Backbone: pre-normalized blocks with multi-head self-attention and SwiGLU feed-forward. Two adaptations for clinical data: 1. Temporal rotary position embeddings, with the rotation angle driven by elapsed time, not token index. Attention between two tokens depends on the hours between them, not on how many events were recorded in between, which matters because event density varies by patient and ward. 2. AdaLN-Zero injects the static context as a global modulation of every block instead of occupying sequence positions, shifting the event manifold into a patient-specific subspace. Context dropout prevents over-reliance on it. This is also how the QA profile enters the model in Study 3: it is a fixed-length vector of scores, concatenated onto the context vector, so no architectural change is needed. Heads: complication risk, time-to-event, and a language-model head (masked LM for the encoder, next-token for the decoder). Same backbone, two attention masks: causal for the decoder, bidirectional with atomic-interval masking for the encoder.
