- How to read: top block = 10k design search around the locked recipe; middle = full-cohort build-up from a stripped baseline; bottom = same deployed model with a different input. The backbone itself comes from the decoder search and is not re-searched - Locked recipe (10k anchor): MLM with atomic interval masking + t_pos / t_local, then phase 3 with the backbone at 0.01 × the head learning rate - + hierarchical MLM masking: hide tokens along the concept hierarchy instead of single intervals (START + END). No gain, dropped - + backbone LR 0.01 → 0.1: let the pretrained backbone move 10× faster in phase 3. It drifts and loses accuracy, dropped - − Phase-3 backbone learning: backbone fully frozen, only the heads train. AUPRC 0.497 → 0.429, so the backbone must adapt a little - Stripped baseline: the recipe on the full cohort with none of the optional loss extras below - + inverse-prevalence weights: rare outcomes up-weighted in the risk BCE by 1 / prevalence. Hurts (0.662 → 0.638, CIs don't overlap), dropped - + focal loss γ = 1: down-weights easy examples so training focuses on hard ones. Within noise, dropped - + curriculum-by-masking p = 0.15: hide 15% of input tokens (interval ends together) during phase 3 as a regularizer. The only consistent gain: deployed model - σ-bin input: KBTA states replaced by knowledge-free bins of each variable's standard deviation, same model. Same AUPRC, LoS error +3.2 h: the clinical names cost nothing and help a little on timing - Point-event input: every interval reduced to a single one-second event, so no duration and no overlap between states. AUPRC 0.672 → 0.593: the model depends on intervals persisting, not just on their names - Takeaways: backbone adaptation is essential; inverse-prevalence weighting is the one clearly harmful arm; CBM is the only full-cohort gain
