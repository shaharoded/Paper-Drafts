- How to read: 10k rows build up the recipe, then drop one piece at a time; full rows confirm on the whole cohort. Each row is the recipe as it stood then, not the final model minus one part - Baseline decoder: the decoder before the search's additions: no time-to-terminal head, no patient pool, no stopping gate - + time-to-terminal head and gate: an extra head predicts hours left to discharge or death at every step; at inference generation stops when it says the end is reached - Locked recipe (+ patient pool): one learned query per outcome reads the whole admission into a summary, trained in phase 3 next to the step-wise risk head. Largest discrimination gain - − Phase-3 alignment: the risk head is never fine-tuned on the model's own generated trajectories, only trained under teacher forcing. AUPRC collapses to 0.213 - − RoPE: attention uses token order instead of elapsed hours. Trajectories run 1.8× too long - − curriculum-by-masking: no input intervals hidden during training, so the model never practices on imperfect history - Short kernel τ = 0.5 h: the soft target fades within half an hour, so upcoming events give almost no early signal (close to switching the kernel off) - √ and log damping: alternative ways of turning the terminal-token class imbalance into an LM-loss weight; both worse than p^0.33 - Prior canonical (cap 0.30): first full-cohort recipe; the time-to-terminal loss may contribute at most 30% of the main loss. Trajectories 2.8× too long - + cap 0.30 → 0.60: time-to-terminal loss allowed up to 60%, so the model learns when to stop: LoS error 148 → 79 h - + p^0.33 weighting (deployed): rare DEATH / RELEASE tokens up-weighted in the LM loss by (imbalance ratio)^0.33. Fixes over- and under-generation: AUPRC 0.587, length ratio 0.90 - Takeaways: phase-3 alignment dominates; RoPE and the soft kernel matter most for trajectory length
