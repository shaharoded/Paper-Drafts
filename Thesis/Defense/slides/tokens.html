About 1.5 minutes. This is the core representational idea. A transformer consumes tokens, but an abstraction is an interval with a duration that one token cannot express. So each interval is split into a START and an END token at its boundaries. Duration becomes the distance between them, read through the temporal encoding rather than as an explicit feature. The Mediator guarantees well-formed sequences: an interval cannot open twice before closing, so every START has its END. Each boundary token is embedded through four hierarchical layers: raw concept (GLUCOSE), abstraction type (GLUCOSE_STATE), concept with value (GLUCOSE_STATE_HIGH), positional role (GLUCOSE_STATE_HIGH_START). So GLUCOSE_STATE and GLUCOSE_TREND share the GLUCOSE embedding, and the START and END of one interval share three of four layers: the model starts out knowing they concern the same parameter and bound the same episode. Time enters by concatenation, not addition: the four concept embeddings and a Time2Vec embedding of time since admission are concatenated (5d wide) and projected back to model dimension. Addition would force identity and position into one subspace; concatenation lets the projection learn how they interact. The vocabulary is clinical by construction, which is what later makes explanations resolve to named concepts.
