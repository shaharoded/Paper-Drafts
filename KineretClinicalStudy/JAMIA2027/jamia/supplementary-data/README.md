`supplementary-code.zip` is the single complete repository archive, retained
locally for editorial requests. Do not upload it through the current portal:
the portal rejected both the full archive and split archive attempts.
The cover letter explains the omission and offers the archive on request.

It includes all Git-tracked files from Mediator/ and kineret-etl-repo/,
including the original curated concept indices, plus README and hash manifest.
Notebook outputs are cleared only in archive copies. Git history, ignored
local data/databases, environments, caches and logs are excluded.
Regenerate with `python package_supplementary.py` from the repository root.
The JAMIA build does not copy ZIP archives to the upload directory.
No CSV conversion is required; the earlier CSV export is a working artifact.
